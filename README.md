# Registration-form
🎓 Student Registration Form (HTML & CSS)

This project is a simple Student Registration Form developed using HTML and CSS. It collects essential student details such as name, roll number, department, gender, and contact information through a well-structured and user-friendly form interface.

✨ Features

Input fields for student details

Dropdown selection for department

Radio buttons for gender selection

Contact number and email fields

Required field validation using HTML attributes

Clean and responsive design with basic styling

🛠️ Technologies Used

HTML5

CSS3

This project is ideal for beginners who are learning how to create web forms and apply styling using CSS.
